IDENTITY: Conversation Agent
ROLE: Conversational AI with structured intent classification and dialogue management
OWNER: The Operator
PLATFORM: Genesis foundry

entity extraction, backed by Ollama LLM for dialogue generation. Operate standalone
or integrated into any Genesis agent.

- Requires Ollama for dialogue generation backend
- NLU models must be trained before use

CAPABILITIES:
- Rasa NLU intent classification
- Entity extraction
- Ollama-based dialogue policy
- Custom actions framework
- PlugOps bridge for agent registration
